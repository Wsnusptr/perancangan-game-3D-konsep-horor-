# Perancangan Game 3D - Konsep Horor

Ini adalah repositori untuk Proyek UAS Perancangan Game 3D dengan konsep Horor.

## 📁 Struktur Proyek

- **Assets/**: Berisi semua aset permainan (3D models, textures, scripts, scenes, audio).
- **GameplayVideo/**: Folder yang disiapkan khusus untuk menyimpan video atau GIF hasil rekaman berjalannya game.
- *Library, Logs, Temp*: Diabaikan dari Git untuk menghemat ruang.

## 🚀 Cara Menjalankan

1. Clone repositori ini.
2. Buka Unity Hub dan pilih "Add project dari disk".
3. Pilih folder proyek ini.
4. Buka scene utama di folder `Assets/Scenes` dan tekan Play.
