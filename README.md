# Perancangan Game 3D - Konsep Horor

Ini adalah repositori untuk Proyek UAS Perancangan Game 3D dengan konsep Horor.

## 🎮 Tampilan Gameplay

> **Catatan:** Anda dapat meletakkan video hasil rekaman gameplay Anda di folder `GameplayVideo` dengan nama file `gameplay.mp4`. Video akan tampil di bawah ini:

Karena ukuran video lebih dari batas rendering otomatis GitHub, silakan klik tombol di bawah ini untuk memutar video gameplay-nya langsung di GitHub:

[![Tonton Video Gameplay](https://img.shields.io/badge/Tonton_Video_Gameplay-▶_Play-red?style=for-the-badge&logo=youtube)](https://github.com/Wsnusptr/perancangan-game-3D-konsep-horor-/blob/main/GameplayVideo/gameplay.mp4)

## 📁 Struktur Proyek

- **Assets/**: Berisi semua aset permainan (3D models, textures, scripts, scenes, audio).
- **GameplayVideo/**: Folder yang disiapkan khusus untuk menyimpan video atau GIF hasil rekaman berjalannya game.
- *Library, Logs, Temp*: Diabaikan dari Git untuk menghemat ruang.

## 🚀 Cara Menjalankan

1. Clone repositori ini.
2. Buka Unity Hub dan pilih "Add project dari disk".
3. Pilih folder proyek ini.
4. Buka scene utama di folder `Assets/Scenes` dan tekan Play.
